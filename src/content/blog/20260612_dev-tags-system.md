## このブログの構成技術

このブログは **Astro x Keystatic x Git x Firebas Hosting** で構成されています！

ファイル構成はこんな感じです。

```
src
├── assets
│   └── # ここには画像やフォントなどの素材が入っています
├── components
│   └── # ここにはHPの表紙のコンポーネントが入っています
├── content
│   └── blog # ここにはblog記事のMarkDownファイルが入っています
├── layouts
│   └── # ここにはblog記事を一覧表示する際のレイアウト定義ファイルが入っています
├── pages
│   └── # ここにはblog記事を表示するためのスラグ変換などの機能が入っています
├── styles
│   └── global.css
└── utils
    └── # ここにはさまざまなヘルパーメソッドなどが入っています
```

デザイン自体は、 **TailwindCSSv4** を利用しています。

## なぜWordPressなどを用いていないの？

ブログ記事などを管理するには、**高価なマネージドサービスやSaaS, VPS、WordPressやDrupalといったCMSサービス** が必要だと考えていませんか？

実は、個人規模や小規模団体のブログ付きHPは、そのようなサービスを **必要としません** 。

なぜかというとそもそも、そこまでの権限管理や記事管理能力、全体のデータベースなどを必要とするのは大企業レベルのWebサービスのみです。
また、WordPressやDrupalといったところは、そういったところをターゲットとしているため、機能が爆発的に多いのです。
利用しない機能のせいで、負荷が高くなってしまった結果、動かすためにはVPSなどを契約する必要が生まれてくるのです。

また少し技術的な話をすると、**WordPressやDrupalはPHPなどを用いた、HTMLレンダリング** をおこなっています。
これは、いわゆるSSRの一貫の技術ですが、こういった随時レンダリングが必要となることから、ページを表示するだけだとしてもサーバーが必要になるのです。
ただし、その分高機能になるわけですね！

## では改めて、なぜFirebase Hostingでいいの？

これは、Astroの強固な事前レンダリング機能を用いてる、ということにつきます。
Astroは事前にHTMLをレンダリングし、そのファイルを生成しておくことで、HPなどのWebページを構築します。

そのため、サーバーに求められるのは、事前にレンダリングしたファイルを返すことのみ。
動的な作業は一切必要ないのです。

だからこそ、静的ファイルホスティングに切り替えることができ、 **FirebaseHosting** のみで、動作が実現するのです。

## ブログ投稿の基盤としてAstroを採用するメリットデメリット

メリットとしては、やっぱりさっきのバックエンドサービスが最低限でいいということ、レンダリングが事前に行われることや独自の最適化技術により、パフォーマンスがめちゃ高いことが
あげられると思います。

ただし、弊害もあります。
ブログ記事の管理が、ファイルベースになり、管理画面などを用意するのが非常に面倒だということ。
あと、記事が増えるたびに全ビルドするので、ビルド時間が伸びるということです。

これ何がめんどくさいって、ある程度 **MarkDownやAstro** に対して理解がある人以外編集できなくなるんです。
いわゆる、CMSがないことによる弊害ですね。

それを解決できるのが、 **Keystatic x Git 差分記録対応記事管理システム** です。

## Keystaticのすごいところ

これは、ファイルベースでCMSを実現でき、かつ保存にGitを組み込んでいることから、自動的に差分管理や権限管理が行えてしまうことです。

確かに軽量なCMSとして **MicroCMS** などがありますし、こちらもかなり便利です。
しかも、逐一アクセスが存在しないAstroとは相性抜群です。

しかし、やっぱり安く済ませたいということ、ある程度ファイルは自分で管理したいということ、これ以上機能を煩雑にしたいくないということを鑑みて、
**Keystatic** の導入を決定しました。

## 改めてSEO対策は？

私たちが行なっているSEO対策は次のとおりです。

- 一旦色んな人にリンクを教えて、Googleのブラウザ経由でアクセスしてもらう
- **Google Search Confole** に登録してインデックスしてもらうようにサイトマップを渡す
- タグシステムを実装する
- **JSON-LD方式** でメタタグを付与する
- XやFacebookようにカード情報を付与する
- Blogの投稿数を増やす
- 単語をふんだんに使う

特に、GSCは確実にやらないといけないことで、インデックスしてもらわないと、まず検索される資格すらありません、っ感じにされます。

また、特に有効だと言われているのは、 **JSON-LD** などに、メタタグを設定することが早いと言われています。
タイトルやディスクリプションなどを入れていくのが効果的だと言われています！
