# 01. このサイトの背景と役割

LinkFarm Tech. 公式サイトが何のために存在し、誰に何を伝えるのかを定義する。
デザインやコードの判断に迷ったとき、最終的な拠り所はこのドキュメントになる。

---

## 1. LinkFarm Tech. とは

奈良県奈良市を拠点とする**学生団体**。法人格は持たない。

| | |
|---|---|
| 設立 | 2026年5月1日 |
| 所在地 | 奈良県奈良市 |
| 活動拠点 | 奈良県内の提携農地（耕作放棄地） |
| 代表者 | 学生代表　増井 崇／専門技術代表　谷川 亮介 |
| 連絡先 | office@linkfarm-tech.com |
| 実績 | 2026年度 奈良市 産学官連携プラットフォーム 補助金 採択 |

構成員は2名。奈良工業高等専門学校の増井がテクノロジー領域とプロジェクトマネジメントを、天理大学の谷川が農業と料理を担当する。

**この2名構成という事実は、サイト設計上の制約であると同時に最大の資産でもある。**
大きな組織に見せかける必要はない。実際に土地を借り、栽培計画を立て、技術基盤を自分たちで組んでいるという一次情報こそが、このサイトが持つ唯一の強みである。

## 2. 解こうとしている課題

| 指標 | 奈良県の順位 | 出典 |
|---|---|---|
| 農業従事者数（人口100人当たり1.43人） | 全国36位 | 農林水産省, e-Stat, 農業構造動態調査 (2016) |
| 経営耕作地面積（販売農家1戸当たり0.94ha） | 全国42位 | 奈良県, 第一編 データの分析編 (2020) |

数値の背後にある実感として、サイトには2つの声を載せている。ひとつは「奈良の有名な農作物が思い浮かばない」という19歳の声、もうひとつは「畑を継ぐ人がいないので荒れ放題になっている」という近隣の高齢農家の声。

**若年層の関心の不在**と**担い手の不在**は同じ問題の裏表であり、片方だけを解いても成立しない。この認識がすべての事業の起点にある。

## 3. 事業構成

事業は3本。**農関係の2本が基本事業**であり、Web制作は現場で培った技術から派生した関連事業という位置づけ。サイト上でもこの階層は「基本事業／関連事業」という組見出しで明示する。

### 基本事業（AGRICULTURE）

**01. 体験型学習プロジェクト**
「学生と創る、あなたとの一年と、この一皿。」

若年層の獲得と耕作放棄地活用のための体験型学習プロジェクト。田植えから収穫、食事までを一本の物語として設計し、離れている期間はテクノロジーで作物との距離をつなぐ。2026年度 奈良市 産学官連携プラットフォーム 補助金の採択事業。

**02. 提携農家様との連携・ボランティア派遣**
「農家の困りごとに、学生の人脈で応える。」

提携農家様が抱える人材問題に対し、運営を始めとしてボランティア派遣などを学生の人脈を通して行う。一方的な支援ではなく共創しながら、関わる人が全員笑顔になることを目指す。

### 関連事業（DERIVED FROM THE FIELD）

**03. Web制作・技術支援**
「地域の活動に、届くかたちを与える。」

自分たちのプロジェクトで培ったWeb・デジタル技術を、同じく地域で動く団体に提供する。一般社団法人NARATIVE様の公式サイト（narative.org）でWebデザインと技術アシストを担当した実績がある。

## 4. このサイトの役割

**このサイトは営業資料ではなく、活動報告である。**

学生団体が信用を得るために必要なのは、洗練された売り文句ではなく「本当に動いている」という証拠である。したがってサイトの中心は、写実的な現場写真と、更新され続ける活動日誌に置く。

### 想定読者と、その人に起こってほしいこと

| 読者 | 目的 | 到達してほしいページ |
|---|---|---|
| 協賛・出資を検討する企業／自治体 | 実在性と継続性の確認 | 団体概要 → 活動日誌 → お問い合わせ |
| 農地の提供を検討する農家 | 何をされるのかの理解、相手の人物確認 | 事業内容 02 → メンバー → お問い合わせ |
| 参加を検討する学生 | 面白そうか、いつ何をするのか | 体験型学習プロジェクト詳細 → お問い合わせ |
| Web制作の相談者 | 実績と技術水準の確認 | 事業内容 03 → 活動日誌 |
| 補助金の審査・報告先 | 事業内容と進捗の確認 | 事業内容 → 活動日誌 |

読者が5種類いることが、**トップページを「表紙＋目次」にしている理由**である。誰が来ても2クリック以内に目的のページへ降りられることを、トップページの唯一の仕事とする。

### このサイトがやらないこと

- **フォームでの問い合わせ受付**。2名体制で個人情報を預かる責任を負わない。窓口はメール1つに絞る。
- **実績の誇張**。「日本初」「業界No.1」のような検証不能な主張は置かない。
- **未確定情報の掲載**。決まっていないことは書かない。

## 6. 用語

サイト内・コード内で表記を統一する。

| 用語 | 表記 | 備考 |

| 団体名 | LinkFarm Tech. | 末尾のピリオドを含む。「LinkFarm」単体では使わない |
| 提携農家 | **提携**農家様 | 「連携農家」とは書かない |
| 提携農地 | **提携**農地 | 「契約農地」とは書かない |
| 耕作放棄地 | 耕作放棄地 | 「休耕地」は統計の引用時のみ |
| ブログ | **活動日誌** | UIラベルは「活動日誌」。URLは `/blog/` を維持（→ [03-route.md](./03-route.md)） |
| 事業 | 事業 | 「サービス」とは書かない。英字ラベルのみ SERVICES |
| 団体概要 | **団体**概要 | **「会社概要」とは書かない。**法人格を持たないため誤解を招く。英字ラベルは ORGANIZATION（COMPANY は使わない）。URLは `/organization/` |
| 自団体の呼称 | 団体 | 「弊社」「当社」は使わない |
