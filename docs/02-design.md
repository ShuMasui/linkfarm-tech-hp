# 02. デザイン規則

このサイトの見た目に関する決定をすべてここに集約する。
実装の正典は [mocks/](./mocks/) のHTMLとCSSであり、本ドキュメントはその「なぜ」を記録する。

---

## 1. 設計の原点

**和紙のような白を地とし、wheat を差し色に、焦茶で書く。写実的で、紙の質感を持つ。**

これが唯一の出発点であり、以下のすべてはここから導かれている。

補助的な参照として [nexusadvisors.co.jp](https://nexusadvisors.co.jp/) の構成を見ている。ほぼ無彩色の紙面、明朝の特大見出し、一句だけの細い下線、広いレタースペースの欧文小ラベル、そして「ページをめくる」という本の比喩。この最後の点が、こちらの「一枚の紙」という考えと同じ方向を向いていたため、**§（節）による丁付け**として取り込んだ。

**意図的に違えた点が一つある。写真である。**
参照サイトは写真を一切使わず抽象的な線画で構成している。対象がAIであれば正しい判断だが、こちらの対象は実在する土地である。曇天で彩度の低い現場写真を、加工せず、暗幕もかけずに載せる。これがこのサイトの信用の源泉であり、参照元との決定的な差分になる。

---

## 2. 色

**wheat 系のみを使う。** 旧デザインの indigo `#4f46e5` / emerald `#10b981` / orange `#f97316` は全廃した。

| トークン | 値 | 用途 |
|---|---|---|
| `--washi` | `#faf8f2` | 和紙の白。ページ全体の地 |
| `--washi-2` | `rgba(224,196,137,.17)` | 二層目の紙。帯セクションのかけ色 |
| `--washi-3` | `#ebe5d6` | 三層目。沈める面（従来のサイクルなど） |
| `--wheat` | `#f5deb3` | 差し色。事業番号、CTAボタン、LinkFarmサイクル |
| `--wheat-deep` | `#e0c489` | wheat の締め。下線、細罫 |
| `--sumi` | `#3d2b1f` | 焦茶。本文、点線、墨の面、ロゴ |
| `--sumi-70 / 50 / 35 / 18 / 10` | `--sumi` のα | 副次テキスト、罫、境界 |

### wheat の扱いに関する制約

**wheat `#f5deb3` は白地に対してコントラストが取れない。** したがって次を禁止する。

- wheat を文字色に使う（背景が焦茶の面を除く）
- wheat の地に白文字を置く
- wheat をCTAボタンの地にして白文字を載せる

wheat が担えるのは**面と線だけ**である。押せるものは原則として焦茶のベタ塗りに `--washi` の文字。

### 帯セクションが不透明色ではない理由

`.section--band` の地色は `--washi-2` という**透過色**である。不透明色にすると、その下に敷いた背景のお皿（後述）を覆い隠してしまうため。同じ理由でフッターの地色も透過色にしている。

## 3. タイポグラフィ

| 役割 | 書体 | ウェイト |
|---|---|---|
| 見出し・数字・柱 | **Shippori Mincho B1** | 500 / 700 / 800 |
| 本文・UI・ラベル | **Zen Kaku Gothic New** | 400 / 500 / 700 |

Noto Serif JP ではなく Shippori Mincho B1 を選んだのは、**活版印刷由来で字画にわずかな荒れがあり、「刷った紙」の質感に寄る**ため。明朝とゴシックという対比は日本語組版の定石だが、この具体的な選択が意図した部分である。

### 組版規則

- `font-feature-settings: "palt" 1` — 和文の詰め組みを有効にする
- `word-break: auto-phrase` — **見出しには必須**。指定しないと「全／てを知る」「保ち続け／る」のような不自然な位置で折り返す
- 本文 `line-height: 1.95〜2.15` — 和文は欧文より行間を広く取る
- 本文の最大幅 `max-width: 33〜40em`
- 見出しサイズは `clamp()` で流動。`.display` は `clamp(2.15rem, 6vw, 4.4rem)`

### 禁止する組版

- **英字ラベルの ALL CAPS を見出しの直上に置く**（いわゆる eyebrow）。柱と事業ラベルの中だけで使う
- 中黒で連結したメタ情報（`A · B · C`）
- リンク文言の末尾に `→` を文字として書く。矢印は独立した `<span aria-hidden>` として持つ

## 4. レイアウト

### 紙面（`.sheet`）

```
width: min(100% - (--rule-inset * 2 + 56px), 1180px);
```

画面端の点線と衝突しない幅を自動で取る。

### 柱（`.hashira`）

下層ページの各節は、左に**柱**、右に本文という見開き構成（`.spread`）を取る。

```
§ 02          土に触れる事業と、
SERVICES      届け方をつくる事業。
事業内容
              ……
```

柱は `position: sticky` でスクロールに追従する。印刷物の柱（ページ上部の見出し）と同じ役割で、いま紙面のどこを読んでいるかを常に示す。1040px 未満では通常のブロックに戻る。

### 左揃え

**全ページで左揃えを基本とする。** 旧デザインは全セクションが中央揃えだったが、中央揃えはLPの定型であり、読み物としては視線の起点が定まらない。

## 5. 構造装置

装置は飾りではなく情報を担う。以下の5つ以外を足さない。

### 画面端の焦茶点線（`.edge-rule`）

このデザインの背骨。画面の左右端から `clamp(14px, 3.2vw, 44px)` の位置に、**3px の点を29pxピッチ**で縦に通す。`position: fixed` なのでスクロールしても動かず、ページ全体が一枚の紙として繋がって見える。

### 背景のお皿（`.plates` / `mock.js`）

丸・ひし形・六角の3種を、**縁のある皿**に見えるよう外周と見込み（内側の輪）の二重線で描く。3×3の粗いグリッドの各マスを35%の確率で空け、残りに種類・大きさ・位置をランダムに配置する。ページを開くたびに配置が変わる。

焦茶12%・線幅1.6px。**最下層（`z-index: -1`）に敷く**。この重ね順は必須で、セクション側に `z-index` を与えると背景色ごとお皿を覆い隠す。

### 右余白の縦組み（`.tategaki`）

`writing-mode: vertical-rl` による和文の縦組み。参照サイトは回転させた欧文を置いているが、こちらは日本語組版として成立する形を選んだ。1340px 未満では非表示。

### 写真プレート（`.plate`）

**写真は台紙に貼った印画紙として扱う。** 13px の余白を残して `--washi` の地に載せ、下にキャプションを置く。文字を写真に重ねない。

これがこのデザインで唯一「大胆さ」を使っている場所である。曇天で彩度の低い写真に暗幕をかけずに済み、写実のまま出せる。

### wheat の下線（`.ul`）

見出しの一句だけに `box-shadow: inset 0 -.14em 0 var(--wheat-deep)` で引く。**マーカーの塗りつぶしは使わない**（黒塗りに見える場面があるため廃止した）。暗い面の上では `--wheat` に切り替える。

### 使わないもの

- 角丸カードの並列（`rounded-3xl` + `shadow` の量産）
- グラデーション背景、ぼかした装飾円、オーロラ
- グラスモーフィズム
- 内容が順序でないところへの 01 / 02 / 03 の付与（サイクル比較とスケジュールは本当に順序なので可）

## 6. 写真

### 現在の素材

| ファイル | 内容 | 用途 |
|---|---|---|
| `src/assets/hero/hero-01.jpg` | 活動を説明している場面 | 事業02、お問い合わせ |
| `src/assets/hero/hero-02.jpg` | 草を刈り整えた耕作地と里山の集落 | トップ表紙、事業詳細の扉 |
| `src/assets/hero/hero-03.jpg` | 川と杉山 | 事業01 |

### EXIF 回転への対応（実装時必須）

`hero-02.jpg` は EXIF orientation=3（180°）、`hero-03.jpg` は=6（90°）。**生のピクセルは回転前の向きで保存されている。**

ブラウザは EXIF を尊重するためモックでは正しく表示されるが、ビルド時の画像最適化で向きが崩れる可能性がある。実装時に**向きを焼き込んだファイルへ正規化する前処理を入れる**こと（`hero-02.jpg` は5.7MBあるのでリサイズも兼ねられる）。→ [04-web.md](./04-web.md)

### ヒーローのカルーセル化（将来の検討事項）

> **現時点では単一の写真プレートで表示している。**
> 今後、現場写真が増えてきた段階で、**ヒーローをカルーセル形式にすることを検討している。**
>
> 検討時に守るべき制約：
> - 自動再生はしない。モーションの方針（次節）に反する
> - 写真に文字を重ねない。プレートの構造は維持する
> - `prefers-reduced-motion: reduce` で切り替えアニメーションを無効化する
> - キャプションは写真ごとに切り替える。撮影地と時期は写真の一部として扱う
> - JavaScript が無効でも1枚目が表示されること

## 7. モーション

**非操作起因のモーションは、ページ全体で1箇所だけ。**

旧デザインにあった全セクションのスクロール連動フェードイン（`.scroll-reveal`）は全廃した。各セクションが順に浮かび上がる演出は生成物の定型であり、読み物のリズムを壊す。

`prefers-reduced-motion: reduce` では、すべての `animation` と `transition` を無効化し、`scroll-behavior` も `auto` に戻す。

ホバー時の遷移（0.18〜0.25秒）は、操作への応答なので許容する。

## 8. アクセシビリティ

- `a:focus-visible` / `button:focus-visible` に `outline: 2px solid var(--sumi)` を明示する
- 現在のページは `aria-current="page"` で示す。色だけでなく下線を併用する
- 装飾要素（点線・お皿・縦組み・矢印）はすべて `aria-hidden="true"`
- ロゴは `<img>` の `alt="LinkFarm Tech."` で社名を伝える
- 本文の文字色 `--sumi` `#3d2b1f` は `--washi` `#faf8f2` に対して十分なコントラスト比を持つ。`--sumi-50` 以下は補助情報にのみ使い、本文には使わない

## 9. ロゴ

`src/assets/linkfarm-logo-yoko.png`（411×75、単色 `#1b003d`、透過PNG）が正のアセット。**このファイルには手を加えない。**

紫 `#1b003d` はパレット外の色であり、そのまま載せるとページ上で最も彩度の高い要素になって浮く。したがって**焦茶 `#3d2b1f` に置き換えた派生画像を使う**。

モックでは `docs/mocks/logo-sumi.png`（822×150、2倍解像度）を生成して `<img>` で置いている。

> 当初は CSS の `mask-image` で元PNGをアルファマスクとして使い、`background-color` で焦茶を塗る方式を採っていたが、環境によって描画されない事例があったため `<img>` + 派生画像に変更した。

## 10. CSS 実装上の注意

### 詳細度の衝突

この設計では**同じ詳細度のルールが色を奪い合う事故**が繰り返し起きた。実装時に必ず確認すること。

| 事故 | 原因 | 対処 |
|---|---|---|
| ヘッダーの「お問い合わせ」から文字が消えた | `.nav a`（0,1,1）が `.btn--fill`（0,1,0）に勝つ | `.nav a.btn--fill { color: var(--washi) }` |
| 現在地のページでボタンの文字が消えた | `.nav a[aria-current]` と `.nav a.btn--fill` が同点で後勝ち | `.nav a.btn--fill[aria-current="page"]` |
| 記事タイトルが素のリンク色になった | セレクタが `.post h3 a` のまま、マークアップは `h2` | `.post :is(h2, h3) a` |

### 重ね順

```
z-index  60   紙のグレイン（body::after, mix-blend-mode: multiply）
z-index  50   ヘッダー
z-index  40   画面端の点線
z-index  39   右余白の縦組み
z-index   0   本文・セクション（z-index を与えない）
z-index  -1   背景のお皿
```

**セクションに `z-index` を与えてはいけない。** 与えると背景色ごとお皿より上に来て覆い隠す。
