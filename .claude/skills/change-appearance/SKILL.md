# 見た目を変える

規則そのものは `docs/02-design.md` に書いてある。**ここには複製しない。**
このスキルが決めるのは、変えるときに踏む順番。

## 1. 規則を読む

作業前に `docs/02-design.md` を読む。色トークンの一覧と、
「wheat は面と線にしか使えない」といった**禁止事項**がそこにある。

**実装の正典は `docs/mocks/` の HTML と CSS。** 迷ったら現物を見る。

## 2. 色は必ずトークンを使う

`src/styles/global.css` に定義された `--washi` `--wheat` `--sumi` などを使う。

**生の色値を新しく書かない。** 既存のトークンで表現できないなら、
それは規則から外れかけている合図なので、トークンを足すか設計を見直す。

## 3. 変更箇所を絞る

| 対象 | 場所 |
|---|---|
| 個別のパーツ | `src/components/`（9個） |
| ページ全体の骨格 | `src/layouts/`（`Page.astro` / `BlogPost.astro`） |
| 色・タイポ・共通規則 | `src/styles/global.css` |
| 各ページ固有 | `src/pages/` |

ロジックをコンポーネントに埋めない（RULE.md の方針）。
加工が要るなら `src/utils/` の純粋な関数に切り出す。

## 4. 目で見る

```
make dev
```

対象ページを開く。`/` `/blog/` `/services/` `/members/` `/organization/` `/contact/`。

## 5. スクリーンショットを撮る

**Claude in Chrome で対象ページを開き、変更前と変更後を撮る。**

- 変更前を撮ってから直す。あとからでは撮り直せない
- 撮るのは変わった箇所が分かる範囲。ページ全体が要るとは限らない
- 撮った画像は PR に貼る。**見た目の変更はスクショが無いとレビューできない**

## 6. 通す

```
make check
```

## 7. PR に貼る

`open-pr` スキルの手順で PR を作り、**本文の「補足」に変更前後のスクショを貼る。**
